# Тихий фокус

Небольшое приложение для спокойной работы: задачи на день и таймер фокуса на 25 или 50 минут с пятиминутным перерывом. Интерфейс на русском языке, адаптирован для телефона и клавиатуры.

## Запуск

Нужен Node.js 20 или новее. Внешних зависимостей нет.

```sh
npm start
```

Откройте http://127.0.0.1:4173. `npm test` запускает проверки данных и таймера.

## Возможности

- Добавление, завершение и удаление задач.
- Выбор задачи для фокус-сессии.
- Пауза, продолжение, сброс и выбор продолжительности таймера.
- Таймер учитывает прошедшее время, даже если вкладка была в фоне.
- Автоматическое сохранение задач в localStorage.
- Поиск по тексту и фильтры «Все задачи», «В работе» и «Готово».

Данные остаются в браузере. Очистка данных сайта удаляет задачи. Таймер не сохраняется после перезагрузки страницы и не выдаёт системные уведомления. Приложение не требует регистрации и не отправляет данные на сервер.

## Устройство проекта

Обычные HTML, CSS и JavaScript без сборки. `core.js` содержит проверку данных и расчёт времени, `app.js` — интерфейс, `server.mjs` — локальный сервер только для файлов приложения. Для статического хостинга достаточно `index.html`, `styles.css`, `app.js` и `core.js`.
